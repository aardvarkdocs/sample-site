# Level 5

You are five levels deep: **Deep nesting → Level 2 → Level 3 → Level 4 →
Level 5**. This is the deepest page in the sample site.

Sitting on this page, every ancestor branch in the sidebar is expanded and marked
as the active trail, with this page highlighted as the current entry — all in the
built HTML, so the sidebar is correct before any script runs. The sidebar has no
depth cap: a sixth level would render exactly the same way.
