# What if I want to raise the cap again later — do I re-confirm every time?

No. Once you've acknowledged it, it stays acknowledged — through later cap changes and plan
changes alike — and you aren't prompted again. The one time it comes back is if you cancel and
later subscribe again: that's a new subscription, so it starts from the default cap with the
acknowledgment cleared.
